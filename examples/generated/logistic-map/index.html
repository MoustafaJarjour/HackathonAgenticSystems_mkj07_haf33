Four Updates of the Logistic Difference Equation

UnderstandExploreCheck the source

The concept

The logistic difference equation x_next = r*x*(1-x) is applied repeatedly, using each output as the next input. Starting from an initial state x0, four updates produce a short trajectory of five values. This demonstrates recurrence without claiming to establish chaos.

Why it matters

The logistic difference equation is the standard minimal example of a deterministic rule whose repeated application can produce complicated behavior. Seeing the first few iterates makes the recurrence concrete before any claims about long-term dynamics are made.

Symbols and terms

x
The state of the population or system at a given iteration, restricted here to the interval [0,1].
r
The growth or control parameter, restricted here to the interval [0,4].
x_next
The state at the next iteration, computed as r*x*(1-x).
x0
The initial state before any update is applied.

How the mechanism works

  1. The recurrence rule

    The source gives the first-order difference equation X_(t+1) = a*X_t*(1-X_t), sometimes called the logistic difference equation. In modern teaching notation we write x_next = r*x*(1-x).

    Source-supported relationship Evidence: logistic_equation, logistic_name

  2. Iterating four times

    Starting from an initial state x0, we compute x1 = r*x0*(1-x0), then use x1 as the input to compute x2, and so on through x4. This produces a short trajectory of five values: x0, x1, x2, x3, x4.

    Teaching simplification

  3. What the short trajectory shows

    Four updates are enough to see the recurrence in action and to compare different r values, but they are not enough to establish long-term behavior such as chaos. The lesson therefore makes no claim beyond the displayed iterates.

Teaching simplification

Try these explorations

  1. Change: Set r to 2 and x0 to 0.5, then set r to 4 and x0 to 0.5.

    Observe: At r=2 the values settle to 0.5 after the first update; at r=4 they move through 0.5, 1, 0, 0, 0.

    Why: This shows how the same recurrence can produce a fixed point or a longer cycle depending on r, without claiming chaos.

  2. Change: Change x0 from 0.5 to 0.25 while keeping r=4.

    Observe: The first update changes, and all later updates shift accordingly because each step feeds the previous result forward.

    Why: This demonstrates that the recurrence uses each output as the next input, so the trajectory is a sequence of dependent states.

Assumptions and limitations

  • Only four updates are shown; this short trajectory does not establish chaos or any long-term asymptotic behavior.
  • The source text is a reprint excerpt; only the recurrence equation and its name are treated as source-supported here.
  • The numerical checks use exactly representable states and do not test sensitivity to small perturbations.

Our teaching simplifications

  • The source uses X_(t+1) = a*X_t*(1-X_t); this lesson renames a to r and X to x for modern teaching notation.
  • The lesson restricts x to [0,1] and r to [0,4] and displays only four updates, which is a pedagogical choice not stated as a theorem in the excerpt.
  • The trajectory visualization is a simple line plot of five values, not a reproduction of any figure from the paper.
