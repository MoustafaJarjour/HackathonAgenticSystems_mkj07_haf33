Four Updates of the Logistic Difference Equation

UnderstandExploreCheck the source

The concept

The logistic difference equation xt+1=rx(1−x) is applied repeatedly, using each output as the next input. Starting from an initial state x0, four updates produce a short trajectory of five values. This demonstrates recurrence without claiming to establish chaos.

Why it matters

The logistic difference equation is the standard minimal example of a deterministic rule whose repeated application can produce complicated behavior. Seeing the first few iterates makes the recurrence concrete before any claims about long-term dynamics are made.

Symbols and terms

x
The state of the population or system at a given iteration, restricted here to the interval [01].
r
The growth or control parameter, restricted here to the interval [04].
xt+1
The state at the next iteration, computed as rx(1−x).
x0
The initial state before any update is applied.

How the mechanism works

  1. The recurrence rule

    The source gives the first-order difference equation Xt+1=aXt(1−Xt), sometimes called the logistic difference equation. In modern teaching notation we write xt+1=rx(1−x).

    Source and teaching notes

    Source-supported relationship Evidence: Claim 2, Claim 1

  2. Iterating four times

    Starting from an initial state x0, we compute x1=rx0(1−x0), then use x1 as the input to compute x2, and so on through x4. This produces a short trajectory of five values: x0, x1, x2, x3, x4.

    Source and teaching notes

    Teaching simplification

  3. What the short trajectory shows

    Four updates are enough to see the recurrence in action and to compare different r values, but they are not enough to establish long-term behavior such as chaos. The lesson therefore makes no claim beyond the displayed iterates.

Teaching simplification

Try these explorations

  1. Change: Set r to 2 and x0 to 0.5, then set r to 4 and x0 to 0.5.

    Observe: At r=2 and x0=0.5, the trajectory is 0.5, 0.5, 0.5, 0.5, 0.5: the initial state is already the fixed point. At r=4 and x0=0.5, the trajectory is 0.5, 1, 0, 0, 0: after reaching 0, the state stays at the absorbing fixed point zero.

    Why: This shows that the same recurrence can have a fixed point from the start or can reach an absorbing fixed point after a few updates, depending on r and x0, without claiming chaos.

  2. Change: Change x0 from 0.5 to 0.25 while keeping r=4.

    Observe: The first update changes, and all later updates shift accordingly because each step feeds the previous result forward.

    Why: This demonstrates that the recurrence uses each output as the next input, so the trajectory is a sequence of dependent states.

Assumptions and limitations

  • Only four updates are shown; this short trajectory does not establish chaos or any long-term asymptotic behavior.

  • The source text is a reprint excerpt; only the recurrence equation and its name are treated as source-supported here.

  • The numerical checks use exactly representable states and do not test sensitivity to small perturbations.

Our teaching simplifications

  • The source uses Xt+1=aXt(1−Xt); this lesson renames a to r and X to x for modern teaching notation.

  • The lesson restricts x to [01] and r to [04] and displays only four updates, which is a pedagogical choice not stated as a theorem in the excerpt.

  • The trajectory visualization is a bar chart of the five values x0 through x4, not a reproduction of any figure from the paper.
